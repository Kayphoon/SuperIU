## 硬约束和已作取舍

- 截图默认只写系统剪贴板。未经用户显式开启，不得保存原图文件，也不得把原始图片放进数据库 BLOB。
- 默认历史仅在内存：文本最多 200 条；图片最多 25 条，仅保留最长边 128 px 缩略图和 OCR 元数据。默认没有原图的历史图片不能恢复复制，这是有意的隐私取舍。
- 菜单中显式开启“保存图片历史到缓存”后，仅后续图片按 hash 保存 PNG。关闭开关删除模块专属磁盘缓存。
- 缓存目录是 `~/Library/Caches/com.superiu.capture/`；图片与 JSON 元数据总上限 **50,000,000 字节**。没有 SQLite/FTS5；最多 225 条记录采用有界数组和文本检索。
- 文本 SHA-256 去重并按 LRU 排序；监控器忽略整次带 Concealed / Transient / AutoGenerated 标记的复制。
- 正常图片复制的 OCR 只读已经完成标注/打码的最终图像，只补历史元数据，不再次写剪贴板。
- 纯文字模式在 OCR 期间发现 changeCount 改变时，不覆盖更新后的剪贴板；同时只保留一个 OCR 任务，不积压全尺寸图像。
- M1 不做自由画笔、富文本、矢量图层树或长截图。不要通过扩大这些功能来处理验收失败。
- 不 bump 版本、不打 tag、不自行合入 master 或发版。推送本分支不等于发布。

## 原生交互验收

必须驱动真实 AppKit 浮层并保存动作日志和截图，不以 CLI 输出或单测替代 GUI。优先用 Mac agent 的 OS accessibility / computer 工具；没有该工具时可用 System Events 发按键，但仍需实际鼠标操作与截图证据。

先记录各 `NSScreen.frame`、`backingScaleFactor`、主屏、负坐标布局，以及自动化截图的坐标系。下表示例坐标应位于当前完整屏幕截图内；若实际布局不同，替换为具体坐标并在每个场景执行前记下，不能混用 AppKit 的左下原点与自动化截图的左上原点。

快捷键的 AppleScript 等价调用：

```sh
# 呼出截图、确认、取消、纯文字模式、打开历史
osascript -e 'tell application "System Events" to key code 19 using {command down, shift down}'
osascript -e 'tell application "System Events" to key code 36'
osascript -e 'tell application "System Events" to key code 53'
osascript -e 'tell application "System Events" to key code 36 using {shift down}'
osascript -e 'tell application "System Events" to key code 9 using {command down, shift down}'
```

这些是独立操作，按场景需要执行，不是一次性连续运行的脚本。

可用以下辅助探针读取剪贴板类型、changeCount 和图像尺寸；只对明确准备的测试内容使用 `pbpaste`：

```sh
swift -e 'import AppKit
let p = NSPasteboard.general
print("changeCount=\(p.changeCount)")
print("types=\((p.types ?? []).map(\.rawValue).joined(separator: ","))")
if let d = p.data(forType: .png), let b = NSBitmapImageRep(data: d) {
    print("png=\(b.pixelsWide)x\(b.pixelsHigh)")
}'
```

| 场景 | 具体调用/动作 | 唯一通过判据与证据 |
| --- | --- | --- |
| 默认无文件复制 | 在测试桌面记录缓存目录前态；`press("cmd+shift+2")`，`drag([[100,100],[600,400]])`，`press("enter")` | PNG 为所选内容、浮层关闭、缓存无新增原图；保存最终粘贴图、动作日志、类型/尺寸和目录前后状态 |
| 取消 | `printf 'qa-before-cancel' \| pbcopy` 后记录 changeCount；呼出、框选、`press("esc")` | 内容仍为 sentinel 且 changeCount 不变；保存两个探针输出和关闭截图 |
| 双击确认 | 呼出、框选后 `doubleClick(350,250)` | 与 Enter 相同的裁切图进入剪贴板且浮层关闭 |
| 八锚点微调 | 对同一选区逐一拖动左下/下/右下/右/右上/上/左上/左；每次记录明确起终点；方向键移动 1 pt，Shift+方向键 10 pt | 八个方向都可调整、不会翻转或越过桌面边界；最终像素尺寸与选区/倍率对应，保存各状态 |
| 矩形档位 | 框选后 `press("r")`，拖动 `[150,150]→[250,250]`；用 `1/2/3` 和 `[/]` 各切换一次，重复画框 | 红/黄/蓝、2/4/6 pt 均生效；确认图包含边框，`Cmd+Z` 撤销最后一个标注 |
| 马赛克 | `press("m")`，拖动 `[300,150]→[400,250]`，Enter | 最终 PNG 为栅格化像素块；被打码区域不会从 OCR 元数据泄出；编辑态黑色遮挡是当前有意预览 |
| 多屏/Retina | 两屏分别放置不同的 TOP / BOTTOM / 中文角标；在每屏框选，再从一屏跨到另一屏；覆盖负坐标和不同倍率 | 全部激活屏幕有浮层，合成方向/边界/倍率正确，不含自己的遮罩；不得用一屏通过代替多屏通过 |
| 非激活与快捷键 | 从 TextEdit 等其他应用呼出，检查系统 frontmost application；点过工具栏后再按 Enter/Esc | helper 不成为 active application；浮层仍收按键；结束后原应用可继续输入；保存动作日志与前后焦点 |
| OCR 纯文字 | 在受控窗口显示 `Hello 中文`，框选，分别用 Shift+Enter 和 Cmd+C；执行 `pbpaste` 和类型探针 | 复制中英文纯文本且没有本次位图，显示“文字已复制”；无文字时提示且不清空原剪贴板 |
| OCR 图文元数据 | 同样框选但按 Enter；随后 Cmd+Shift+V，在历史搜索 `Hello` 和 `中文` | 剪贴板仍是 PNG，搜索找到对应缩略图；晚到 OCR 不覆盖后来复制的 sentinel |

| 显式磁盘历史 | 在菜单开启图片历史，再复制新图，搜索/复制该条，关闭开关 | 开启后 hash PNG+文本元数据；原图可复制；总文件字节≤50,000,000；关闭后专属缓存消失 |
| 无原图历史 | 默认模式图片入历史后尝试复制该条 | 明确提示未保存原图，不把128px缩略图伪装成原图复制 |
| 权限失败与重试 | 未授权的测试身份首次呼出，按实际系统流程拒绝/授权，再重试 | 不改变原剪贴板、不留下遮罩或进程；授权后可重新截图；记录是否需要重启及实际 bundle id |
| 退出/孤儿 | 记录 helper PID；通过本次应用 Quit 正常退出；另在受控实例检查父进程意外退出的 EOF 路径 | helper PID 退出、热键/菜单消失，无本次孤儿；仅处理本次持有的进程 |

不要为权限场景清除用户的 TCC、剪贴板历史或应用数据；隔离测试身份不可用时记为 BLOCKED。

## 性能与释放

分别测新增原生 helper 和整个 Electron 应用，不能用现有 Electron 总内存替代 helper 指标，也不能只看源码断言达标：

```sh
pgrep -fl SuperIUNative
# 从上面确认本次 APP 下的 helper PID 后执行：
ps -o pid=,ppid=,rss=,%cpu=,etime= -p "$HELPER_PID" \
  | tee -a "$EVIDENCE/helper-resources.txt"
```

在启动后闲置、截图结束、OCR 完成后三个稳定状态记录 RSS/CPU，并重复受控截图确认内存不随次数持续增长。`ps` 的 RSS 为 KiB，换算为字节；目标常驻 ≤35 MB，CPU 采样显示 0.0%，不宣称轮询数学上零消耗。不得偷偷改成“增量私有内存”来宣布通过。

唤起延迟目标 <80 ms。分别记录“按键→首个浮层”和“按键→可框选”时间，保存工具时间戳/帧证据；不能用透明面板先出现掩盖实际尚不能框选的延迟。源码现在先显示预热 Panel，再等 ScreenCaptureKit 返回图像，这一点尤其需要实测。

检查截图关闭后全屏 `CGImage`、Canvas layer、捕获任务被释放；OCR 期间仅一份最终选图持有，完成后释放。打码结果、已逐出记录或已清空历史不能被晚到 OCR 复活。

检查缓存字节总量用各文件 `stat` 求和，并检查25图/7天的逐出与对应元数据同步；`du -sk ~/Library/Caches/com.superiu.capture` 可作为额外物理磁盘记录，不代替字节统计。

## 已知边界与验收注意点

- Apple SDK 类型检查、Swift actor 隔离、Carbon/TCC、嵌套 helper 的签名和实际归属都未在 Linux 验证；先以真实 Mac 编译结果为准。
- 历史面板和提示当前为中文，helper 没有透传宿主语言/主题偏好；检查系统 light/dark 下可读性，并报告与宿主的实际差异。
- 图片缓存和历史是本机功能，与连接 local/gateway/remote/custom URL 模式无关；onboarding 也应有菜单栏 helper。
- “保存图片历史”开关允许持久化图片及有界文本元数据；默认无痕要求优先，不把自动存盘当作修复。
- `session-order` 是已记录的基线问题，不能为让本次验收全绿而削弱测试；若需要另行修复，单独记录其复现、owner 与授权范围。
- 收到屏幕权限或自动化授权拒绝时，记录 BLOCKED，不通过其他工具绕过拒绝。
